# Book Capture

카메라와 갤러리를 함께 쓰며 책 사진에 네모·페이지·감상을 남기는 Android 앱입니다.

[최신 APK 다운로드](https://github.com/lakP44/book_capture_cam_releases/releases/latest/download/BookCapture.apk)

1. 휴대폰 브라우저에서 위 APK를 다운로드하고 설치합니다. 압축 해제와 GitHub 로그인은 필요하지 않습니다.
2. 기존 앱이 있으면 삭제하지 않고 업데이트합니다.
3. 이후에는 앱의 위쪽 ⋮ 메뉴 또는 카메라 설정에서 **앱 업데이트**를 열어 확인·다운로드·설치합니다.
4. 처음 앱 안에서 설치할 때 Book Capture의 앱 설치 허용이 필요할 수 있습니다. 마지막 Android 설치 확인은 직접 눌러 주세요.

촬영·사진 정리·편집은 오프라인으로 동작합니다. 인터넷은 사용자가 요청하는 업데이트 확인·다운로드에 사용하며 사진이나 감상을 업로드하지 않습니다. 업데이트 다운로드는 GitHub에 연결됩니다.

Android 10 이상이 필요합니다. 스토어 밖 APK 설치에 대한 Android 보안 안내가 나올 수 있습니다.
